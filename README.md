# Northwind SQL Analysis

This project focuses on analyzing sales data from the Northwind database using SQL Server.

## Tools
- SQL Server
- SQL Server Management Studio (SSMS)

## Analysis

### Initial Data Review
- Reviewing table structures and record counts
- Checking for NULL values
- Validating product prices

### Product Analysis
- Calculating gross and net sales
- Ranking products by net sales
- Analyzing units sold

### Customer Analysis
- Analyzing customer orders and sales
- Ranking customers by order count
- Identifying top customers
- Examining customers with a single order

### Discount Analysis
- Comparing sales across discount levels
- Analyzing discounted and non-discounted sales

### Shipping Analysis
- Calculating shipping durations
- Analyzing shipping performance

## Notes

Gross sales represent sales before discounts, while net sales are calculated after discounts.

Since product cost data is not available in the dataset, net sales should not be interpreted as profit.

## Project Status

SQL analysis completed; Power BI reporting planned.
